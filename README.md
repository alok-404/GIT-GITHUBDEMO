# Git & GitHub Demo

This repository is a hands-on practice space for learning Git and GitHub.
It covers the core workflow: `init`, `add`, `commit`, `branch`, `merge`, and `push`.
The `GIT-GITHUBDEMO/` folder holds a sample repository used for experiments.
Use it to try out branching, resolving merge conflicts, and working with remotes.
Clone it, make changes on a new branch, and open a pull request to practice collaboration.
